## Goal

Port `cognee/modules/truth_subspace/build.py:build_truth_subspace`
(lines 108-299) into a Rust orchestration function,
`cognee_cognify::build_truth_subspace`, and wire it into `improve()` as an
opt-in stage that runs after session distillation and before default
enrichment. This is the task that actually *drives* the pure math
(P2-01/P2-02) and I/O wiring (P2-03/P2-04) landed by earlier Phase-2 tasks —
without it, `build_truth_subspace`/`use_truth_weight` stay inert, matching
the locked "Phase 2 execution deferred but fully spec'd" decision. The
stage is default-off end-to-end (SDK, HTTP, bindings, CLI), so this task
changes no default behavior.

## Implementation steps

1. **Port the two deferred constants** into
   `crates/truth-subspace/src/constants.rs`: `TRUTH_NODE_SET: &[&str] =
   &["session_learnings"]` (`constants.py:2`) and `pub fn
   truth_session_node_set(session_id: &str) -> String {
   format!("session_learnings:{session_id}") }` (`constants.py:6-7`).
   Re-export from `lib.rs`.

2. **Create `crates/cognify/src/memify/build_truth_subspace.rs`** citing
   `build.py:1-6`. Define `pub const NODE_EMBED_BATCH_SIZE: usize = 64`
   (`build.py:39`) and
   `#[derive(Debug, Clone, Default, PartialEq)] pub struct
   TruthSubspaceResult { pub anchors: usize, pub nodes_scored: usize, pub
   signature: String, pub truth_epoch: i64 }`.
   `TruthSubspaceResult::default()` **is** Python's `empty_result`
   (`build.py:119`) — no separate constant needed.

3. **Signature — infallible.** Every internal Python step fails open to a
   dict; the `try/except` in `improve.py:207-221` is a redundant second
   net around a call that can't raise. Port as
   `pub async fn build_truth_subspace(dataset_id: Uuid, session_ids:
   &[String], graph_db: Arc<dyn GraphDBTrait>, vector_db: Arc<dyn
   VectorDB>, embedding_engine: Arc<dyn EmbeddingEngine>, k: usize) ->
   TruthSubspaceResult` — no `Result`/error enum; there is no reachable
   `Err` path. `session_ids` empty is valid input (mirrors Python's
   `Optional[...] = None`) and takes the rebuild branch (step 9); this
   task's only call site always passes non-empty (gated by
   `has_sessions`), but keep the empty branch working for future callers.
   `dataset_id: Uuid` replaces Python's `_resolve_dataset`
   (`build.py:102-105,121-124`) — the caller (Stage 2d) resolves the
   dataset the same way Stage 4 does
   (`cognee_database::ops::datasets::get_dataset_by_name`), so this
   function skips Python's `get_authorized_existing_datasets` ACL
   re-check (Rust's owner/tenant scoping has no per-call ACL layer here,
   matching sibling stage functions). Compute `dataset_id_str =
   dataset_id.to_string()` once (matches `str(dataset_obj.id)`).

4. **Fetch learning statements** (`build.py:56-85`). Node-set names: if
   `session_ids` empty use `TRUTH_NODE_SET`, else map each id through
   `truth_session_node_set`. Call `graph_db.get_nodeset_subgraph("NodeSet",
   &names, "OR")` (`"NodeSet"` is the literal node `type` — see
   `crates/models/src/document.rs:168`; `"OR"` is Python's unstated
   default, `graph_db_interface.py:571`). On `Err`, `warn!` and treat as
   zero nodes. Keep only nodes with `type == "DocumentChunk"`; read
   **only** `text` (no `"name"` fallback — `build.py:80`, distinct from
   step 8's node-text extraction); `.trim()`; dedupe by
   `.to_lowercase()` (accepted casefold divergence, same as P2-02), first-
   seen order preserved (do not sort yet).

5. **Empty-statements short-circuit** (`build.py:132-134`): return
   `TruthSubspaceResult::default()`.

6. **Load existing centroids** (`build.py:136-140`). Call P2-03's
   `load_centroids`; on failure use `Vec::new()`.
   `previous_epoch = existing_centroids.iter().map(|c|
   c.truth_epoch).max().unwrap_or(0)` (`build.py:142`).

7. **Dedupe + sort by id** (`build.py:143-152`). Insert each statement
   into a `BTreeMap<String, String>` keyed by
   `cognee_truth_subspace::learning_id(statement)` — `BTreeMap`
   insert-overwrite (last-wins) + sorted iteration matches Python's dict
   comprehension + `sorted(..., key=item[0])` exactly. **Do not** reuse
   P2-02's `unique_learning_vectors` (first-wins) — `build.py` doesn't
   call it here either. Split into `learning_ids`/`learning_texts`.

8. **Signature**: `cognee_truth_subspace::align::stable_signature(&learning_ids)`
   (`build.py:153`).

9. **Embed learning texts — ONE call, not batched** (`build.py:155-165`).
   `embedding_engine.embed(&refs).await`. On `Err`, return `{anchors:
   existing_centroids.len(), nodes_scored: 0, signature, truth_epoch:
   previous_epoch}`. On success, widen each `f32` to `f64`.
   `updated_at = chrono::Utc::now().timestamp_millis()` (`build.py:167`).
   `learning_vectors: Vec<(String, Vec<f64>)>` = zip of ids and vecs.

10. **`build_for_epoch` closure** (`build.py:170-186`): non-empty
    `session_ids` → `extend_centroids_with_learning_vectors(&dataset_id_str,
    &existing_centroids, &learning_vectors, epoch, Some(updated_at), k)`; else
    `build_centroids_from_learning_vectors(&dataset_id_str, &learning_vectors,
    epoch, Some(updated_at), k)` (no `existing_centroids` arg). Note the
    `updated_at: Option<i64>` param — pass `Some(updated_at)`, not a bare
    `i64`. Plain sync closure (P2-02's functions are pure/sync).

11. **Rebuild + empty check** (`build.py:188-190`):
    `rebuilt_centroids = build_for_epoch(previous_epoch)`; if empty,
    return `TruthSubspaceResult::default()` — **discard the
    already-computed `signature`**, faithfully reproducing this Python
    quirk (`build.py:189-190` returns the top-level `empty_result`, not a
    signature-carrying partial).

12. **Change detection + upsert** (`build.py:192-207`). If
    `centroids_changed(&existing_centroids, &rebuilt_centroids, 1e-6)` (note the
    required `tolerance` third arg): `current_epoch =
    previous_epoch + 1`; `centroids = build_for_epoch(current_epoch)`;
    call P2-03's `upsert_centroids` (fail-open → `{anchors:
    centroids.len(), nodes_scored: 0, signature, truth_epoch:
    current_epoch}`). Else `current_epoch = previous_epoch; centroids =
    existing_centroids` (no upsert call at all).

13. **Load ALL `DocumentChunk` nodes, then extract ids/texts**
    (`build.py:211-241,42-47`). Use
    `graph_db.get_filtered_graph_data(&HashMap::from([(Cow::Borrowed("type"),
    vec![json!("DocumentChunk")])]))` — same call shape as
    `lexical_retriever.rs:145`. **Diverge from Python**: Python avoids
    `get_filtered_graph_data` because it runs queries via `asyncio.gather`,
    deadlocking Kuzu's single-connection subprocess backend
    (`build.py:216-218`) — no Rust equivalent constraint exists, so prefer
    it over `get_graph_data()` + in-memory filtering; document the choice
    inline. On `Err`, return the shape-5 partial result (step 12's
    upsert-failure shape). Then for each returned node: skip unless
    `type == "DocumentChunk"`; `text = node_data.get("text").or(get("name"))
    .unwrap_or("")`, `.trim()` — this **is** `_node_index_text`'s
    name-fallback, unlike step 4's learning-text fetch. Skip empty id/text.
    If the resulting `node_texts` is empty, return the shape-5 result.

14. **Batch-embed node texts, then compute per-node coords**
    (`build.py:88-99,209,252-263`). Chunk `node_texts` by
    `NODE_EMBED_BATCH_SIZE` (64); on a chunk's `Err`, `warn!` and pad with
    `Vec::new()` per text (NEUTRAL coords), preserving order. Widen each
    resulting vector to `f64`; `coords = pad_coords(&node_coords(&node_vec_f64,
    &centroid_vecs), k)` where `centroid_vecs = centroids.iter().map(|c|
    c.centroid.clone()).collect()`. Insert into `scored: HashMap<String,
    NodeTruthState>` keyed by node id. **No per-node try/except needed** —
    `node_coords`/`pad_coords` are total (empty node vec still yields valid
    all-zero coords), so Python's per-node catch (`build.py:261-263`) is
    dead-code insurance in both languages — do not add artificial
    fallibility to mirror it. If `scored` ends up empty (`build.py:265-271`),
    return the shape-5 result.

15. **Persist, then return** (`build.py:273-299`):
    `graph_db.set_node_truth_state(&scored)` (P2-04); on `Err`, return the
    shape-5 result; on `Ok`, `nodes_scored =
    write_result.values().filter(|ok| **ok).count()`. Return `{anchors:
    centroids.len(), nodes_scored, signature, truth_epoch: current_epoch}`
    with an `info!` summary log.

16. **Wire into `improve.rs`**: add `build_truth_subspace: bool` to

## Parity notes

- **Infallible return** (`-> TruthSubspaceResult`, no `Result`) — matches
  Python's `-> dict`, which never raises past its own boundary.
- **Six return shapes**, reproduce each exactly: (1) dataset not found →
  `default()`; (2) no learning statements → `default()`
  (`build.py:132-134`); (3) learning-embed failure → `{anchors:
  existing.len(), nodes_scored: 0, signature, truth_epoch:
  previous_epoch}` (`build.py:158-165`); (4) `rebuilt_centroids` empty →
  **`default()`, dropping the already-computed `signature`**
  (`build.py:188-190` — a preserved Python quirk, not "fixed"); (5)
  centroid-upsert / node-load / no-node-texts / no-scored / persist
  failure → `{anchors: centroids.len(), nodes_scored: 0, signature,
  truth_epoch: current_epoch}` (`build.py:196-283`, five call sites, one
  shape); (6) full success → `{anchors: centroids.len(), nodes_scored,
  signature, truth_epoch: current_epoch}` (`build.py:294-299`).
- **Learning-statement text is NOT `_node_index_text`**: the fetch path
  reads only `"text"` (`build.py:80`); only chunk-node scoring falls back
  to `"name"` (`build.py:42-47,237`).
- **Last-wins dedup** (step 7, `BTreeMap` insert-overwrite) intentionally
  differs from P2-02's first-wins `unique_learning_vectors` — do not swap.
- **Single embed call for learnings vs batched for chunks**:
  `NODE_EMBED_BATCH_SIZE = 64` applies only to chunk-node embedding
  (step 14); learning-text embedding (step 9) is always one call
  (`build.py:157`).
- **`get_filtered_graph_data` vs `get_graph_data`**: intentional Rust
  divergence (step 13) — Python's Kuzu/`asyncio.gather` deadlock has no
  Rust equivalent; the filtered call scans the same node set, just
  server- instead of client-side filtered.
- **f32 → f64 widening**: `EmbeddingEngine::embed` returns `Vec<Vec<f32>>`;
  everything feeding `cognee-truth-subspace` (`f64`-based, per P2-01) is
  cast component-wise. No Python analog (Python floats are already 64-bit).
- **Per-node fail-open is dead code in Rust** (step 14) —
  `node_coords`/`pad_coords` never fail; do not add artificial
  fallibility just to mirror Python's defensive per-node `try/except`.
- **No backfill for existing datasets** (locked decision 7): a dataset
  cognified before this lands simply has no `TruthCentroid` vectors or
  `truth_alignment` node properties; the first opt-in run behaves like
  Python's first run (`previous_epoch` defaults to `0`). No migration.
- **Wire-ahead-of-Python**: Python's HTTP router does not expose
  `build_truth_subspace` on `ImprovePayloadDTO` today (SDK-only); adding
  it to the Rust DTO is intentionally ahead of Python's current wire
  surface per this task's brief — inert (default `false`), no effect on
  existing cross-SDK parity tests.
